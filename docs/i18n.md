# 新界面文案资源

此基础设施在 P1.6 前独立建立，不迁移现有界面文案，也不增加语言切换控件。

- 前端新文案放 web/src/locales/zh-CN.json，使用平面命名键。
- 从 web/src/i18n.js 调用 t(key, parameters)，插值使用命名占位符，如 common.count 的 count。
- 未知语言回退中文；缺少键或占位参数明确抛错，不静默显示错误文案。动态状态名先用 hasMessage 检查或映射到固定键，不能把任意服务端文本当作资源键。
- 参数是纯文本数据，不在 i18n 中解释 HTML。React 按文本渲染；不得使用 dangerouslySetInnerHTML 展示资源或导入说明。
- 新导入组件放 web/src/ip，ESLint 禁止 JSX 硬编码文本，以及 title/placeholder/aria-label 的直接字符串。CSS 类名、协议字段与用户的模块/端口数据不属于翻译文案。
- 后端领域诊断仍使用根目录 locales/zh-CN.json，暂不合并已有后端或旧 UI 文案，以保持本任务边界清楚。

单测验证资源、0 值插值、回退、缺失键与原型属性隔离；npm test、lint、typecheck 均包含该基础设施。
