## 编辑闭环

自然语言请求 -> 紧凑设计/检索卡片 -> LLMClient -> typed ops -> 新语义校验 -> 最多三轮修复 -> 只读差异预览 -> 用户选择并接受 -> 再次校验与快照核对 -> 一个撤销步骤。

- 旧 Copilot 对话入口保留，但 bd_generate 只生成待确认提案，不直接改图或生成 HDL；没有模型确认工具。
- 卡片只含 ID/version、参数、端口，不含 RTL、注释或描述。设计上下文保留解析位宽和表达式，不含坐标；错误反馈使用 code+params/location 及受影响端口，不用 message 驱动修复。
- 六类 ops 为 add_instance/remove_instance/set_param/add_external_port/connect/disconnect。未知操作/端点类型拒绝，接口级总线未实现。
- 用户选择子集后重新应用与校验；非法原提案不能通过取消操作绕过门禁。源文件、库或设计变化会使确认失败。
- 删除需要新面板逐轮显式授权；旧 SDK 不能扩大权限。新旧模型请求共用每分钟 10 次、256KiB 请求限制；原有本地访问保护、输出限制和超时仍保留。

## 边界与后续

- 本轮未调用真实模型。Mock 全绿是确定性回归证据，不是模型能力、抗注入率或真实环境泛化的测量结果；real 模式必须手动传入 --allow-network。
- P3.5/P3.6 本机独立性能分别出现 324.908/415.510ms 和 432.439/474.121ms 的中位数/最大值。按 P2.6 已批准策略仅警告，未放宽预算或继续优化校验器；最终 P3.7 样本通过，但不能据此宣称本机性能无波动。
- 大提案操作列表可滚动，预览不支持直接编辑；候选与实际参数面板分离。大设计可视化与增量校验留到 Phase 4。
- 保留 Vite 大 chunk/use-client 和 Actions Node20 迁移警告；它们不改变本次功能门禁结果。
- 限流是单机单进程保护，服务不是公网多租户系统。不能把语义校验当成仿真、综合、CDC、时序或硬件签核。
- Phase 2B 暂缓：后续再定义接口级端点/总线操作及相关规则，不能扩充本次 ops/schema 时破坏 v2/v3 与历史 golden。
- 下一步可单独授权真实模型小规模评测，再以同一 20 例报告比较提示和模型变化；Phase 4 先量测交互性能，不在本轮实现。
